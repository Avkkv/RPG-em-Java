# RPG em Java - "O Caso 47"

## Resumo
Um RPG investigativo no terminal em que o jogador evolui como investigador, coleta pistas e enfrenta suspeitos através de interrogatórios. Seus atributos determinam a eficiência das ações e o Random introduz incerteza nos confrontos. Ao final, o jogador precisa conectar as pistas e formular sua própria conclusão sobre o caso. Dependendo das escolhas e evidências coletadas, diferentes finais podem ser alcançados.
